# Passé composé cheat sheet

## Regular

- er -> é
- re -> u
- ir -> i

## Irregular avec être

**aller:**  

- je/tu/il -> allé
- elle -> allée
- nous/vous/ils -> allés
- elles -> allées  

**descendre**  
**Note:** Also an avoir conjugation ?

- je/tu/il -> descendu
- elle -> descendue
- nous/vous/ils -> descendus
- elles -> descendues

**mourir**  

- je/tu/il -> mort
- elle -> morte
- nous/vous/ils -> morts
- elles -> mortes
